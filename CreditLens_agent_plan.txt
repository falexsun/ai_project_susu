ПРОМПТ ДЛЯ АГЕНТА:

================================================================

--- ЗАДАЧА 3.1: Архитектура MLP на PyTorch ---

ПРОМПТ ДЛЯ АГЕНТА:

Создай src/model.py с реализацией нейросети на PyTorch для кредитного скоринга.

Класс CreditNet(nn.Module):
- Вход: размер входных признаков
- Архитектура: Linear → BatchNorm → ReLU → Dropout(0.3) →
               Linear → BatchNorm → ReLU → Dropout(0.2) → Linear(1)
- Скрытые слои: [256, 128, 64]
- Выход: sigmoid (вероятность дефолта)

Класс CreditTrainer:
- Метод train(X_train, y_train, epochs=100, lr=0.001)
- BCELoss с pos_weight для балансировки классов
- Adam оптимайзер с weight_decay=1e-4
- Early stopping при отсутствии улучшения 15 эпох
- Логирование loss каждые 10 эпох
- Метод predict_proba(X) → вероятности
- Метод save(path) и load(path)

Добавь __main__ блок: загружает данные из data/processed/,
обучает модель, сохраняет в data/processed/model.pt

ПРОМПТ ДЛЯ АГЕНТА:

Создай src/explainer.py с классом CreditExplainer.

__init__(self, model, X_train, feature_names):
- Инициализирует shap.DeepExplainer (для PyTorch)
  или shap.KernelExplainer как fallback

Метод explain(X_sample) → dict:
- Возвращает {'shap_values': ..., 'base_value': ...,
              'feature_names': ..., 'prediction': ...}

Метод plot_waterfall(shap_values, feature_names, prediction):
- Строит waterfall plot через shap.plots.waterfall
  или вручную через matplotlib
- Красный = повышает риск, зелёный = снижает риск

Метод plot_global_importance(X_test):
- Bar chart глобальной важности признаков (top-15)
